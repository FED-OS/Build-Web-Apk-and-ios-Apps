This placeholder is only used when you build a fully offline bundled app and haven't dropped in your own files yet.

  1. Live site (easiest): set server.url in capacitor.config.json — the app loads your website and this file is ignored.
  2. Bundled files: replace everything in www/ with your built site (index.html, css/, js/, assets/ …) and remove server.url if set. The app then works fully offline.

Update appId (a unique reverse-domain id, e.g. com.yourcompany.appname) and appName in capacitor.config.json.
